Предварительные реальные Node-проверки и Chrome прошли. Chrome проверил backspace, clear, согласованность клавиатуры/кнопок и экран 360px. Это прежний ограниченный набор: зелёные проверки не доказывают, что агент добавил требуемые семь UI-сценариев. Поздний этап `host_tests_1` не был допущен из-за отрицательных ревью; поэтому флаг execution `proposalTestsExecuted=false` не заменён на true.

## Что исправлено в Factory

- Добавлен отдельный допуск T05 с новым разрешением владельца; T04-разрешение не подходит. Для T05 требуется полный проверенный префикс T01–T04.
- Исправлено возвращаемое множество проверенных предшествующих задач: оно соответствует выбранной задаче.
- Добавлены запуск T05 из постоянной очереди, восстановление одного отклонённого черновика и накопительный учёт расходов через остановку.
- Добавлена поддержка точного T05 scope в Node/Chrome host evidence; прежние сценарии и ответы сохранены. Отсутствующие доказательства не объявляются проверенными.
- Инструкция исправления для T05 разрешает только её файл тестов и сохраняет существующие ожидаемые ответы.
- Отдельный host-only адаптер восстанавливает только отсутствующее описание; требует совпадения хеша сохранённого ответа и неизменных байтов патча. Это не переписывание кода Calculator вручную.
- В этот адаптер добавлен ранний отказ для правки, которая меняет только комментарии/форматирование, без исполняемого изменения. Используется уже установленный и закреплённый lockfile парсер tsx; новые зависимости не добавлялись.
- Добавлены регрессионные проверки допуска, бюджета, полноты предшествующего префикса, проверки host evidence, сохранения патча, невозможности расширить scope и отказа от неисполняемой правки.

Security, Reviewer, Tester, CI, авторизация, изоляция браузера, exact-SHA и проверки публикации не ослаблены. Юридический агент выключен.
