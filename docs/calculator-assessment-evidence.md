# Exact-proposal host evidence for the saved UI task

The saved t02 UI is corrected, but its original Security/Reviewer verdicts do
not approve the corrected files. Restoring a canonical proposal with an empty
assessment prefix still requires fresh Security, Reviewer and Tester verdicts.

`collectCalculatorAssessmentEvidence` is a trusted host API for this narrow
clear/backspace task. It requires a real commit/blob-verified core snapshot and
host functions that run proposal checks and browser checks. A serialized report
or owner/model JSON cannot manufacture its WeakMap capability. A host restoring
previous browser evidence must authenticate the immutable artifact/run and all
file hashes, bind the core hash and exact proposal digest, and provide that
verification through its trusted browser-check adapter. Merely reading JSON is
not verification.

The model receives only a bounded report, fixed export signature, file/blob/SHA
metadata and explicit unverified areas. The full unchanged arithmetic source is
never serialized. Evidence is bound to the exact in-memory prepared proposal,
task ID, base commit and core SHA. Incorrect/stale/incomplete/unsafe proof fails
before model bytes or tokens are reserved. The complete augmented request still
passes the unchanged context, TPM, task-byte and token budgets.

Provide the host capability through the final function argument to
`createCalculatorModelTeam`. With no provider, packets retain their existing
unverified-test disclosure. With verified evidence, the three independent roles
can cite `host-checks@<proposal digest>`. Their verdicts still cannot assert test
execution, publication or overall completion. The executor's real proposal
checks, independent gates, publisher lease and exact-candidate CI remain
mandatory. This API grants no continuation/replay/budget/write permission and
does not change the legal-agent setting.

The evidence covers only the saved task's backspace and clear scenarios.
Keyboard, narrow-screen layout, chained expressions, other browsers and phones
remain unverified. It does not complete step 8 or establish automatic CI delivery.
