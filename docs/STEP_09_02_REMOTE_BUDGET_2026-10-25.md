## Что изменилось

Добавлен `github/projectModelBudgetStore.ts`, реализующий прежний интерфейс общего бюджета. Вместо локального диска используются Git objects и отдельный ref `state/project-model-budget/<projectKey>` в **Onay-Agents-Factory**. Ветка содержит только `project-model-budget.json`, без исходников и workflow. Основная ветка проекта не используется как хранилище.

Запись привязана к прочитанной версии. Новый коммит имеет точного прежнего родителя; ref обновляется с `force:false`. Два разных дочерних коммита от одной версии не могут оба стать её продолжением. Устаревшая версия останавливается до вызова модели, без автоматического повтора.

Даже при одинаковых данных каждый конкурентный коммит получает случайный nonce в сообщении. Поэтому второй одинаковый запрос не превращается в успешное обновление «уже тот же SHA». Этот случай отдельно воспроизведён тестом.

Адаптер разрешает только добавление одной записи с сохранением прежнего префикса и идентичности разрешения. Изменение старых расходов, удаление записей, повтор идентификатора и сброс через повторную инициализацию отвергаются. Служебные refs не удаляются и не обновляются принудительно.

Общая проверка схемы `parseProjectModelBudgetState` используется счётчиком и удалённым адаптером. В Git сохраняются только идентификаторы, SHA256 и числовые расходы; ключи, сообщения модели и полный исходник не попадают в метаданные. Проверяются точный ref, тип commit, единственный безопасный файл дерева, SHA1 дерева/блока и корректный base64. Чужие пути и дополнительные поля отвергаются.

Неопределённое подтверждение записи и HTTP-ошибки не повторяют запрос. Если ref уже обновился, а ответ потерян, новый исполнитель увидит сохранённый расход. Прежняя попытка останется остановленной. Некорректное подтверждение не даёт разрешения отправить запрос провайдеру.
