# Factory: подтверждение PR после публикации — 25.10.2026

**Обработан случай задержки обновления SHA в карточке PR после подтверждённого push.** Исправление находится в существующей feature-ветке Factory и Draft PR #75. Код калькулятора не изменялся; новых вызовов модели нет.

## Что установлено

Раньше Factory один раз читала `/pulls/{number}` после push и требовала новый SHA немедленно. Если карточка PR ещё показывала прежний SHA, публикация останавливалась как неопределённая, хотя сам Git ref уже подтверждал новый коммит. Отдельная сверка чтением ранее подтверждала уже опубликованный результат и его CI.

В историческом журнале T05 сохранены `pr_detail`, HTTP 200 и подтверждённый push, но не конкретное отклонённое поле ответа. Поэтому нельзя доказательно утверждать, что именно `head.sha` был причиной того единственного ответа. Обнаруженный механизм задержки воспроизведён тестами и обработан; прочие несовпадения по-прежнему означают отказ.

## Изменённое поведение

- После принятого push выполняется максимум **4 чтения** того же PR с паузами 250, 750 и 1500 мс.
- Дополнительное чтение разрешено только когда ответ успешный, все поля PR верны, а его SHA равен точному предыдущему SHA задачи.
- Новый точный SHA обязателен для успеха. Прежний или произвольный коммит не принимается за опубликованный кандидат.
- До и после каждого чтения проверяются актуальные Git refs целевой и базовой веток.
- Чужой репозиторий, другой PR, смена ветки/базы, закрытие, merge или потеря Draft сразу останавливают подтверждение.
- HTTP 429/403, тайм-аут, ошибка JSON и неопределённый ответ не повторяются. После исчерпания четырёх чтений сохраняется неопределённый результат.
- Повторных push, POST, генерации, вызовов модели или создания нового PR нет. Одноразовый допуск publisher сохраняется.

Выделен `github/calculatorPrConfirmation.ts`; существующий publisher использует его только для подтверждения уже существующего PR. Создание нового PR и все прежние проверки авторизации, родителя коммита, допустимых файлов, ролей и CI сохранены. Юридический агент не запускается.
