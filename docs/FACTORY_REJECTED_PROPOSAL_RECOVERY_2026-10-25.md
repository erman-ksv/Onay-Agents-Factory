# Factory — подготовка исправления из сохранённого ответа

25 октября 2026. Продолжение [сохранения отклонённых ответов автора](FACTORY_REJECTED_AUTHOR_CAPTURE_2026-10-25.md).

## Что завершено

Добавлен `prepareCalculatorRejectedProposalRecovery`: доверенный host может подготовить ограниченный запрос Frontend на исправление из приватного checkpoint. Ранее контекст исправления собирался из переданного вручную объекта отклонения; теперь есть отдельная связка с сохранёнными доказательствами. Она не запускает модель, не меняет приложение и не выдаёт разрешения на продолжение.

Проверяются внешний ожидаемый SHA256 файла и полная идентичность checkpoint, исходный план, задача, репозиторий, ветка и commit SHA. Снимок исходников должен быть настоящим host capability с тем же набором путей; JSON-копия его не заменяет. Ожидаемые digest и identity должен предоставить доверенный host из проверенного удалённого барьера. Самоподписанный файл не является авторизацией, а эта функция не проверяет и не захватывает удалённый барьер.

Допускается только окончательно сохранённый отказ валидатора исходного предложения Frontend: `generate_1`, попытка 1, `proposal_changes_invalid`, подтверждённое завершение HTTP, без публикации, подготовленного предложения и оценок специалистов. Консервативные расходы сохранены в метаданных результата. Отсутствие причины, HTTP 429/500, неопределённый запрос, явный отказ агента и отклонённое повторное исправление не превращаются в запрос нового исправления.

Используется существующий ограниченный контекст: commit SHA, хеши файлов, выборочные фрагменты, реальные диагностики и отклонённое предложение как недоверенные данные. Лимиты — 6000 расчётных токенов с резервом ответа и 16000 байт запроса. Непоказанный исходник и непроведённые проверки явно перечислены. Полные исходники остаются в памяти host. Возвращаемый `request.body` приватен и не предназначен для журналов/публичных артефактов; метаданные содержат только ссылки, хеши, расходы и признаки отсутствия разрешения.

Существующий builder также использует защищённое копирование отклонённых данных до чтения полей. Циклы и вычисляемые свойства отклоняются без выполнения getter.

## Что ещё открыто

Это подготовка запроса, а не автоматический цикл самокоррекции. Исполнитель не подключён к новому builder и не отправляет его результат. Для отправки нужен отдельно авторизованный host-путь, одноразовый удалённый захват продолжения, действующая проверка владельца и общий лимит; затем все прежние проверки результата, Security, Reviewer, Tester, реальные тесты и CI. Ни байты checkpoint, ни возвращаемые метаданные не заменяют эти разрешения.

Функция пока поддерживает только Frontend: существующая инструкция коррекции привязана к этой роли. Она не выдаётся за общий механизм Developer и не повторяет отклонённую попытку repair.

Новых вызовов модели: **0**. Предыдущий лимит не расширен, реальный общий счётчик не инициализирован: запрос оператора остаётся `inspect`, `ownerDecision: null`. Main и Calculator/Onay не изменены. Пилот не повторялся. Merge, deployment, Codespaces, платные API и новые агенты не использовались. Юридический агент отключён. Шаг 9 целиком не закрыт.
