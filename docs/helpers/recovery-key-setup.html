Ключ восстановления Factory

Для первой настройки. Ключ создаётся только в этом браузере: страница не отправляет его в сеть и не сохраняет в хранилище.

Имя секрета:
FACTORY_RECOVERY_KEY_BASE64

Затем создайте отдельный ключ для поля Value. Используйте этот же ключ в следующих запусках Factory.

Значение ключа не отправляйте в чат.

Открыть Actions Secrets → New repository secret → вставить Name и Value → Add secret.
